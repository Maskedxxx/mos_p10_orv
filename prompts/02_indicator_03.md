нормативный правовой акт города Москвы по одному индикатору эффективного
регулирования.

ИНДИКАТОР 3 — «Актуальность законодательства»
Каждая ссылка акта ведёт на то, что существует сегодня: акт, на который
ссылается документ, действует; орган существует под этим названием.

<входные_данные>
Выше этой инструкции идут два блока:

  «## ПОЛНЫЙ ТЕКСТ АКТА» — акт целиком в формате markdown;
  «## ПАСПОРТ АКТА»      — вспомогательное описание структуры акта в формате JSON.

Паспорт — только подсказка: всё проверяй сам по полному тексту акта.
</входные_данные>

<правовая_база>
Статус ссылок проверяй в правовой базе Гарант, интернет — только для того,
что база не нашла.

  garant_find_hyperlinks(text) — распознать ссылки на акты. Передай одним
    вызовом все ссылки акта списком реквизитов, по одной на строку, —
    не весь текст акта. У каждой распознанной ссылки — topic документа.
  garant_document_redactions(topic) — статус акта: rs_Actual — действует;
    rs_ActualAbolished — утратил силу; rs_ActualPreactive — не вступил в силу.
  garant_search — найти акт, который не распознан. По реквизитам:
    is_query = true, query «Number(123-ПП) & Date(01.02.2020;01.02.2020)»
    (дата ДД.ММ.ГГГГ с ведущими нулями, всегда диапазоном). По словам
    названия: is_query = false. Орган: найди положение о нём («Положение
    о Департаменте …») и проверь статус положения.

Не повторяй один и тот же вызов. Ссылка на акт в базе:
https://internet.garant.ru/#/document/<topic>.

Интернет: WebSearch — найти страницу, WebFetch — открыть её. Не больше
{{ПОТОЛОК_ЗАХОДОВ}} ЗАХОДОВ ПОИСКА В ИНТЕРНЕТЕ; заход — поиск плюс открытие
найденного. Статус бери только с открытой страницы. Своды правил, ГОСТ
и другие нормативы, к которым у базы нет доступа, ищи на сайтах нормативной
документации: meganorm.ru, normacs.info, docs.cntd.ru.
</правовая_база>
